Scalable Azure Data Engineering Pipeline with Medallion Architecture

An Azure lakehouse pipeline that takes raw data through Bronze, Silver and Gold layers into analytics-ready tables.

What I did

2026
  • Built an end-to-end Azure pipeline in Azure Databricks and PySpark that automates ingestion, cleansing and transformation through Bronze, Silver and Gold Medallion layers, producing analytics-ready datasets.
  • Used Delta Live Tables (DLT) for orchestration and incremental processing, and Star Schema models with SCD Type 2 for historical tracking.
  • Enforced data governance with Unity Catalog and optimized the Gold layer for Power BI reporting.
