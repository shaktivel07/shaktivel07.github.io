UPI Transaction Analytics Dashboard

A Power BI dashboard built on official NPCI UPI statistics to track India's digital payments ecosystem.

What I did

2026
  • Designed a Power BI dashboard on official NPCI UPI transaction statistics to analyze and monitor India's digital payments ecosystem at scale.
  • Built a dimensional data model with reusable DAX measures, plus KPIs, trend analysis, MoM and YoY growth, rolling averages, cumulative metrics and transaction distribution insights.
  • Used Power Query for data preparation and delivered executive-ready self-service BI reports across multiple time periods.
